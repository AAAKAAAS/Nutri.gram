# 🍎 NutriGram – Smart Food Scanner

🔗 **Live App:** https://nutrigi.netlify.app

---

## 🚀 Overview

NutriGram is a web application that analyzes food products and provides nutritional insights.
Users can upload images of food items, and the app processes them to display key nutritional information.

---

## 🛠️ Tech Stack

* **Frontend:** React (Vite), TypeScript, Tailwind CSS
* **Backend / BaaS:** Supabase
* **Deployment:** Netlify

---

## ✨ Features

* 📸 Upload food images
* 🧠 AI-powered food analysis
* 📊 Nutritional breakdown display
* 🔐 Authentication using Supabase
* 📈 User history & analytics (if implemented)
